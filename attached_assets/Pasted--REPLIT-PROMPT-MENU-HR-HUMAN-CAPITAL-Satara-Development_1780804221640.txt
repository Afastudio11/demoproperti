# REPLIT PROMPT — MENU HR (HUMAN CAPITAL)
## Satara Development Internal Dashboard

---

## KONTEKS

Dashboard internal Satara Development sudah berjalan dengan sidebar utama:
Executive Overview, Daftar Proyek, Akuisisi Lahan, Perencanaan, Legal & Perizinan,
Marketing, Administrasi KPR, Produksi, Serah Terima, **HR** (← ini yang dibangun), Settings.

**Tugas:** Bangun seluruh halaman dan sub-menu untuk menu **HR**.

Sistem ini bukan HR System konvensional yang hanya mengurus absensi, cuti, dan payroll.
Ini adalah **Satara Human Capital Management System (SHCMS)**: sistem pengelolaan aset
manusia yang dirancang untuk mendukung ekspansi Satara ke proyek-proyek baru.

Tujuan inti sistem ini adalah memastikan orang yang tepat, di posisi yang tepat,
dengan KPI yang tepat, dengan budaya yang tepat, dan dengan kompensasi yang tepat.

**Fungsi:** Halaman ringkasan untuk CEO. Semua angka dihitung otomatis dari modul di bawah.

|--------|--------|

Scatter chart dengan sumbu X = Performance Score dan sumbu Y = Potential Score.
Setiap titik = satu karyawan (nama ditampilkan saat hover).
Kuadran:
- Kanan atas (High Potential + High Performance): Rising Star
- Kanan bawah (Low Potential + High Performance): Solid Performer

- Kiri bawah (Low Potential + Low Performance): Underperformer

**Baris 4 — Workload Summary:**
Tabel ringkasan beban kerja per divisi (kapasitas vs beban aktual).

**Baris 5 — Expansion Readiness per Proyek Baru:**

|--------|-------------|-----------|
| Barru | 78% | 1 Site Manager, 2 Marketing, 1 Admin |

**Baris 6 — Flight Risk Alerts:**
Daftar karyawan dengan Flight Risk Score Medium atau High.

### 6. COMPETENCY MATRIX
**Route:** `/hr/kompetensi`

**Fungsi:** Mendefinisikan kompetensi yang dibutuhkan per jabatan dan mengukur gap per karyawan.

**Form input definisi kompetensi per jabatan:**

| Field | Tipe | Keterangan |
|-------|------|-----------|
| Jabatan | Text | |
| Divisi | Select | |
| Nama Kompetensi | Text | Contoh: Excel, Site Management, QC, Akuntansi |
| Deskripsi | Textarea | |
| Target Skor (1-100) | Number | Standar minimum untuk jabatan tersebut |

**Form input skor kompetensi per karyawan:**

| Field | Tipe | Keterangan |
|-------|------|-----------|
| Karyawan | Select | |
| Kompetensi | Select | dari definisi kompetensi jabatan karyawan tersebut |
| Skor Aktual (1-100) | Number | Hasil assessment |
| Tanggal Assessment | Date | |
| Assessor | Text | |
| Catatan | Textarea | |

**Kompetensi standar per divisi (seed data awal):**

Finance: Excel, Akuntansi, Cashflow, Budgeting
Produksi: Site Management, QC, Material Control, K3

```
Skill Gap per kompetensi = Target Skor - Skor Aktual

```

- Tabel skill gap: daftar kompetensi yang masih di bawah target, diurutkan dari gap terbesar

### 13. WORKLOAD ANALYSIS
**Route:** `/hr/workload`

**Fungsi:** Mengukur apakah beban kerja setiap divisi seimbang dengan kapasitas SDM yang ada.

**Form input beban kerja per divisi per bulan:**

| Field | Tipe | Keterangan |
|-------|------|-----------|
| Divisi | Select | |
| Periode | Date | |
| Kapasitas (poin) | Number | Default 100 per divisi, bisa disesuaikan |
| Beban Aktual (poin) | Number | Estimasi oleh HR Manager / Division Head |
| Catatan Beban | Textarea | Deskripsi pekerjaan yang menyebabkan overload |

**Kalkulasi:**
```
Workload Ratio = Beban Aktual ÷ Kapasitas × 100%

Status:
  < 80%  = Underloaded (biru)
  80-100% = Normal (hijau)
  100-120% = Overloaded (kuning, alert sedang)
  > 120%  = Critical Overload (merah, alert kritis)
```

**Tampilan:**

| Divisi | Kapasitas | Beban | Workload Ratio | Status |
|--------|-----------|-------|---------------|--------|
| Marketing | 100 | 80 | 80% | Normal |
| Administrasi | 100 | 120 | 120% | Overloaded |
| Legal | 100 | 140 | 140% | Critical Overload |

- Bar chart: perbandingan kapasitas vs beban per divisi
- Alert kritis: Legal Overload 40%, Admin Overload 20%
- Rekomendasi teks otomatis: "Legal overload 40%. Pertimbangkan penambahan 1 staf legal
  atau redistribusi tugas dari proyek yang less urgent."

### 15. HUMAN CAPITAL SCORE
**Route:** `/hr/hc-score`

**Fungsi:** Skor kesehatan SDM perusahaan secara keseluruhan untuk CEO.

**Komponen dan bobot:**

| Komponen | Bobot | Kalkulasi |
|---------|-------|-----------|
| KPI Achievement | 30% | Rata-rata KPI Achievement semua karyawan aktif |
| Productivity | 20% | Revenue per Employee vs target (dari Modul 10) |
| Competency | 20% | Rata-rata Competency Score semua karyawan |
| Culture | 15% | Culture Score perusahaan (dari Modul 12) |
| Recruitment | 15% | Recruitment Readiness (posisi terisi ÷ kebutuhan) |

**Kalkulasi total:**
```
Human Capital Score = (KPI×0.30) + (Productivity×0.20) + (Competency×0.20)
                    + (Culture×0.15) + (Recruitment×0.15)

Status:
  > 80 = SEHAT (hijau)
  60-80 = WASPADA (kuning)
  < 60 = KRITIS (merah)
```

**Tampilan:**
- Angka besar dengan gauge chart dan label status
- Breakdown per komponen: skor aktual, bobot, kontribusi ke total
- Trend: Human Capital Score 6 bulan terakhir

## TIGA FITUR KHUSUS SATARA

### A. Talent Map

### B. Flight Risk Score
**Route:** `/hr/flight-risk`

Form input per karyawan per kuartal (diisi HR Manager):

| Field | Tipe | Keterangan |
|-------|------|-----------|
| Karyawan | Select | |
| Periode | Date | |
| Lama Tidak Naik Jabatan (bulan) | Number | |
| Selisih Gaji vs Pasar (%) | Number | Negatif = di bawah pasar |
| Skor Kepuasan Kerja (1-10) | Number | Hasil 1-on-1 atau survei internal |
| Ada Tawaran Luar | Select | Tidak / Mungkin / Ya |
| Catatan | Textarea | |

**Kalkulasi:**
```
Flight Risk Score = rata-rata berbobot:
  - Lama tidak naik jabatan (semakin lama = skor lebih tinggi) (25%)
  - Selisih gaji vs pasar (semakin negatif = skor lebih tinggi) (35%)
  - Skor kepuasan kerja (inverted: semakin rendah = skor lebih tinggi) (25%)
  - Ada tawaran luar (Tidak=0, Mungkin=50, Ya=100) (15%)

Status:
  < 40 = Low (hijau)
  40-70 = Medium (kuning)
  > 70 = High (merah)
```

## UI/UX REQUIREMENTS

1. **Org Chart interaktif:** Di Modul 2, tampilkan org chart sebagai pohon hierarki yang
   bisa di-zoom dan di-pan. Klik node karyawan → buka popup ringkasan: foto (opsional),
   jabatan, KPI Achievement, Performance Score, Competency Score.

2. **Radar chart kompetensi:** Di Modul 6, setiap karyawan memiliki radar chart yang
   menampilkan skor aktual vs target per kompetensi secara visual.

3. **Scatter chart Talent Map:** Di HR Dashboard dan Modul Talent Map, gunakan scatter
   chart interaktif. Hover per titik menampilkan nama, divisi, Performance Score,
   dan Potential Score.

4. **Quick KPI input:** Staf HR bisa menginput realisasi KPI bulanan semua karyawan
   dalam satu tabel (seperti spreadsheet inline) tanpa harus buka form satu per satu.

5. **Integrasi data otomatis:** KPI yang bersumber dari modul lain (Marketing, Administrasi
   KPR, Legal, Produksi) ditarik otomatis setiap awal bulan. HR tidak perlu input manual
   untuk data yang sudah tercatat di modul operasional.

6. **Alert Expansion → Recruitment:** Saat Expansion Readiness mendeteksi posisi tanpa
   kandidat, tombol "Buka Rekrutmen" otomatis membuat record kebutuhan baru di Modul 3
   dengan data posisi yang sudah terisi.

7. **Export payroll:** Halaman Compensation bisa di-export ke Excel dengan format yang
   siap digunakan untuk transfer gaji (nama, rekening, nominal).

8. **Mobile-friendly:** Halaman yang perlu diakses dari lapangan: input kultur harian
   (jika ada), dan lihat performance ringkasan personal (karyawan melihat KPI sendiri).

9. **Number format:** Semua rupiah: `Rp 750.000.000`. Semua tanggal: `15 Januari 2026`.
   Semua persentase: `87,0%`. Semua skor: `87/100`.

10. **Status badge warna standar:**
    - Hijau: Excellent / SEHAT / Low Risk / Siap
    - Kuning: Good / WASPADA / Medium Risk / Perlu Development
    - Oranye: Needs Improvement / Overloaded
    - Merah: Poor / KRITIS / High Risk / Critical Overload
    - Abu-abu: Data belum diisi
