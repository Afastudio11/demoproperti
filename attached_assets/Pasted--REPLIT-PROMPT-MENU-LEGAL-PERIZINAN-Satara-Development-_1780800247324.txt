## Satara Development Internal Dashboard

---

## KONTEKS

Dashboard internal Satara Development sudah berjalan dengan sidebar utama:
Executive Overview, Daftar Proyek, Akuisisi Lahan, Perencanaan, **Legal & Perizinan**
(← ini yang dibangun), Marketing, Administrasi KPR, Produksi, Serah Terima, Settings.

**Tugas:** Bangun seluruh halaman dan sub-menu untuk menu **Legal & Perizinan**.

Divisi ini adalah penjaga legalitas seluruh siklus proyek. Tidak ada unit yang bisa diakadkan
tanpa SHM pecah. Tidak ada konstruksi yang bisa dimulai tanpa PBG. Tidak ada serah
terima tanpa SLF. Fungsi inti divisi adalah memastikan setiap proyek memiliki legalitas
yang lengkap di setiap tahapan: Lahan → Perizinan → Sertifikasi → Serah Terima.

Pipeline legalitas proyek mengikuti alur berikut:
**Lahan & KKPR → Lingkungan → Siteplan & PBG → Infrastruktur → Pembangunan → Sertifikasi → Serah Terima**

### 2. PERMIT TRACKER
**Route:** `/legal/permit`

**Fungsi:** Tracking kelengkapan seluruh dokumen perizinan per proyek.
Izin bersifat per proyek/siteplan, bukan per unit atau per tahap.

#### Daftar Izin per Proyek
**Route:** `/legal/permit`

Tampilan tab per proyek (SN1 / SN2 / SN3 / SN4 / Barru / Villa Sinoa).

Untuk setiap proyek, tampilkan tabel checklist izin:

**Izin yang ditracking (hardcode sebagai default, bisa dikonfigurasi di Settings):**

Kelompok A — Perizinan Dasar:
- KKPR (Kesesuaian Kegiatan Pemanfaatan Ruang) — via Dinas PUPR / OSS
- Persetujuan Lingkungan: SPPL (skala kecil) / UKL-UPL (skala menengah) / AMDAL (skala besar) — via Dinas Lingkungan Hidup

Kelompok B — Perizinan Bangunan:
- Persetujuan Siteplan — via Dinas PUPR
- PBG (Persetujuan Bangunan Gedung, pengganti IMB) — via aplikasi SIMBG
- SLF (Sertifikat Laik Fungsi)
- Sikumbang (register perumahan subsidi)

Kelompok C — Izin Teknis Khusus:
- Andalalin (Analisis Dampak Lalu Lintas) — via Dinas Perhubungan, untuk perumahan skala besar
- SIPA (Surat Izin Pengambilan Air Tanah) — via Balai Wilayah Sungai (BWS)

**Kolom tabel per izin:**

| Field | Tipe | Keterangan |
|-------|------|-----------|
| Nama Dokumen | Text | Nama izin |
| Status | Select | Belum Diajukan / Dalam Proses / Selesai / Tidak Diperlukan |
| Tanggal Pengajuan | Date | |
| Target Selesai | Date | |
| Tanggal Aktual Selesai | Date | |
| Nomor Dokumen | Text | Nomor surat / registrasi resmi |
| PIC | Select | Nama staf legal yang handle |
| Instansi | Text | Nama instansi penerbit |
| File Dokumen | Upload | PDF scan dokumen resmi |
| Catatan | Textarea | |

**Kalkulasi otomatis:**
```
Permit Readiness (%) = jumlah izin berstatus "Selesai"
                       ÷ jumlah izin berstatus selain "Tidak Diperlukan"
                       × 100%
```

Tampilkan progress bar Permit Readiness di header setiap tab proyek.

#### Tambah / Edit Izin
**Route:** `/legal/permit/new` dan `/legal/permit/:id/edit`

Form mengikuti field tabel di atas, dengan tambahan:
- Pilih Proyek (Select)
- Pilih Kelompok Izin (Select: Perizinan Dasar / Perizinan Bangunan / Izin Teknis Khusus)

#### Detail Izin
**Route:** `/legal/permit/:id`

Tampilan detail satu dokumen izin:
- Header: nama izin, proyek, status badge, PIC
- Timeline riwayat perubahan status
- Preview / download file dokumen
- Catatan dan tindak lanjut

### 6. LEGAL DOCUMENT ARCHIVE
**Route:** `/legal/arsip`

**Fungsi:** Repositori terpusat semua dokumen legal yang sudah diupload dari modul-modul di atas,
dilengkapi dengan fitur pencarian dan filter.

**Tampilan:**

- Search bar: cari berdasarkan nama dokumen, nomor dokumen, atau proyek

SHM Split Tracker, dan Legal Issue Tracker. Tidak ada input manual khusus di halaman ini.

## DATABASE SCHEMA (SUPABASE)

```sql
-- Dokumen perizinan per proyek
permit_documents (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  permit_group text,          -- perizinan_dasar, perizinan_bangunan, izin_teknis
  permit_name text,           -- nama izin: KKPR, PBG, SLF, dll
  institution text,           -- instansi penerbit
  status text,                -- belum_diajukan, dalam_proses, selesai, tidak_diperlukan
  submission_date date,
  target_date date,
  actual_date date,
  document_number text,       -- nomor surat / registrasi resmi
  pic text,
  file_url text,              -- URL file upload di Supabase Storage
  notes text,
  created_at timestamptz,
  updated_at timestamptz
)

-- Riwayat perubahan status izin
permit_status_history (
  id uuid PRIMARY KEY,
  permit_id uuid REFERENCES permit_documents(id),
  from_status text,
  to_status text,
  changed_by text,
  changed_at timestamptz,
  notes text
)

-- Data lahan per tahap
land_stages (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  stage_code text,            -- T1, T2, T3, dst
  stage_identity text,        -- nama pemilik / identitas: "Dg. Ari", "H. Ani"
  land_area numeric,          -- luas dalam m²
  target_kavlings integer,    -- jumlah kavling target
  certificate_number text,    -- nomor sertifikat induk
  stage_status text,          -- belum_mulai, negosiasi, ajb, balik_nama, pemecahan_shm, pisah_pbb, siap_bangun, selesai
  notes text,
  created_at timestamptz,
  updated_at timestamptz
)

-- Checklist item legal per tahap lahan
land_legal_checklist (
  id uuid PRIMARY KEY,
  land_stage_id uuid REFERENCES land_stages(id),
  item_name text,             -- Survey Legal, Cek SHM, Negosiasi, AJB, Balik Nama, Pemecahan SHM, Pisah PBB
  item_order integer,         -- urutan tampil
  status text,                -- belum, proses, selesai
  submission_date date,
  target_date date,
  actual_date date,
  pic text,
  file_url text,
  notes text,
  updated_at timestamptz
)

-- SHM Split Tracker
shm_split_records (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  land_stage_id uuid REFERENCES land_stages(id),
  target_split integer,       -- total kavling yang harus dipecah
  realized_split integer,     -- jumlah SHM yang sudah pecah
  last_updated date,
  pic text,
  notes text,
  created_at timestamptz,
  updated_at timestamptz
)

-- Legal Issue Tracker
legal_issues (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  title text,
  object_description text,    -- objek sengketa
  category text,              -- sengketa_batas, klaim_kepemilikan, masalah_shm, perizinan, lainnya
  risk_level text,            -- high, medium, low
  description text,
  status text,                -- aktif, mediasi, sidang, selesai, ditutup
  pic text,
  start_date date,
  target_resolution date,
  completed_date date,
  document_urls text[],
  created_at timestamptz,
  updated_at timestamptz
)

-- Riwayat perubahan status isu
legal_issue_history (
  id uuid PRIMARY KEY,
  issue_id uuid REFERENCES legal_issues(id),
  from_status text,
  to_status text,
  changed_by text,
  changed_at timestamptz,
  notes text
)
```

## UI/UX REQUIREMENTS

1. **Hierarki tiga level pengguna:** Dashboard Legal menampilkan tiga tampilan berbeda
   yang bisa diakses via toggle:
   - Staff Legal: detail checklist per tahap per item (untuk update harian)
   - Head Legal: ringkasan progress per tahap dengan bottleneck highlights
   - CEO: empat metric utama + matrix ringkasan + alert bottleneck

2. **Quick update checklist:** Staf legal bisa mengubah status item checklist langsung
   dari tampilan daftar tanpa membuka halaman detail. Setiap perubahan tercatat otomatis
   dengan timestamp dan nama pengguna.

3. **Progress bar visual:** Setiap tahap lahan dan setiap proyek menampilkan progress bar
   dengan persentase yang dihitung otomatis dari data checklist.

4. **Color coding status:**
   - Hijau: Selesai / Legal Readiness >80%
   - Kuning: Proses / Legal Readiness 60-80%
   - Merah: Belum Mulai / Legal Readiness <60% / Isu High Risk
   - Abu-abu: Tidak Diperlukan

5. **Alert SHM ke Administrasi KPR:** Jika SHM unit belum pecah dan customer sudah
   mencapai status SP3K, tampilkan warning di Legal Dashboard dan di halaman detail
   customer di modul Administrasi KPR.

6. **Mobile-friendly:** Halaman update checklist Land Legal Tracker harus bisa diakses
   dari HP oleh staf legal yang sedang di lapangan atau di kantor BPN.

7. **Upload dokumen:** Setiap item checklist mendukung upload file (PDF/JPG/PNG,
   maksimum 10MB per file). File disimpan di Supabase Storage dengan penamaan terstruktur:
   `[project_code]/[module]/[stage_code]/[item_name]_[timestamp].[ext]`

8. **Search global:** Di Legal Document Archive, sediakan search bar yang bisa
   mencari berdasarkan nama dokumen, nomor dokumen, proyek, dan PIC.

9. **Export:** Halaman Permit Tracker dan Land Legal Tracker bisa di-export ke Excel
   dalam format ringkasan status per proyek.

10. **Number format:** Semua tanggal: `15 Januari 2026`. Semua persentase: `82,0%`.
    Luas lahan: `1.250 m²`.

11. **Status badge warna standar:**
    - Abu-abu: Belum Diajukan / Belum Mulai
    - Biru: Dalam Proses / Negosiasi
    - Kuning: Menunggu Persetujuan / AJB / Balik Nama
    - Oranye: Pemecahan SHM / Pisah PBB
    - Hijau: Selesai / Siap Bangun
    - Merah: Terlambat / High Risk / Ditolak
