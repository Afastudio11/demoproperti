## KONTEKS PROYEK

Saya sedang mengembangkan dashboard internal untuk perusahaan developer perumahan bernama **Satara Development**. Dashboard ini sudah berjalan dan memiliki sidebar navigasi utama dengan menu berikut:

- Executive Overview (aktif, sudah ada)
- Daftar Proyek (sudah ada)
- Akuisisi Lahan (sudah ada)
- **Perencanaan** ← INI YANG AKAN KITA KERJAKAN
- Legal & Perizinan (sudah ada)
- Marketing (sudah ada)
- Administrasi KPR (sudah ada)
- Produksi (sudah ada)
- Serah Terima (sudah ada)
- Settings (sudah ada)

**Tugas spesifik:** Bangun seluruh halaman dan sub-menu untuk menu **Perencanaan**, yang berfungsi sebagai Divisi Perencanaan (Planning Intelligence Center) perusahaan. Divisi ini adalah "otak analisis dan pengambilan keputusan proyek" sebelum proyek dieksekusi oleh divisi lain.

## SPESIFIKASI DETAIL SETIAP HALAMAN

### 1. COMMAND CENTER
**Route:** `/perencanaan`
**Fungsi:** Dashboard ringkasan CEO — halaman pertama yang dibuka saat masuk menu Perencanaan.

**Komponen yang harus ada:**
- Metric cards (baris atas): Total Proyek Aktif, Total Unit Pipeline, Total Revenue Pipeline (Rp), Total Profit Estimasi (Rp), Land Bank Coverage (bulan)
- Project Health Score cards: satu card per proyek aktif, menampilkan skor Market / Cashflow / Konstruksi / Legal / Marketing masing-masing 0-100, dengan warna hijau (>80) / kuning (60-80) / merah (<60)
- Early Warning alerts: list notifikasi otomatis jika ada delay, over budget, atau gap akad
- CEO Recommendation panel: ringkasan rekomendasi AI per proyek (teks)
- Cashflow Forecast chart: proyeksi 12 bulan ke depan (line chart, cash in vs cash out)

**Data source:** Agregasi otomatis dari semua modul di bawah. Tidak ada input manual di halaman ini.

```
- Jumlah ASN + karyawan swasta (bobot 20%)
- Tingkat pengangguran terbalik (bobot 15%)
Normalisasi ke skala 0-100
```

#### 5c. Hasil Studi Kelayakan
**Route:** `/perencanaan/feasibility/:project_id/hasil`

**Kalkulasi otomatis:**
```
Total Revenue      = Harga Jual/Unit × Total Unit
Total Cost         = Semua komponen biaya + contingency
Gross Profit       = Total Revenue − Total Cost
Margin             = (Gross Profit ÷ Total Revenue) × 100%
ROI                = (Net Profit ÷ Total Cost) × 100%
IRR                = Dihitung dari cashflow per bulan
NPV                = Net Present Value dengan discount rate input (default 12%)
Payback Period     = Bulan ke-N saat kumulatif cashflow = 0
BEP (unit)         = Total Fixed Cost ÷ (Harga/Unit − Variable Cost/Unit)
```

**Standar Satara — tampilkan status lolos/tidak:**
- ROI minimum 35% → jika <35% tampil merah
- IRR minimum 20% → jika <20% tampil merah
- Payback maksimum 24 bulan → jika >24 tampil merah
- Margin minimum 25% → jika <25% tampil merah

## DATABASE SCHEMA (SUPABASE)

Buat tabel-tabel berikut:

```sql
-- Master proyek (relasi ke semua modul)
projects (
  id uuid PRIMARY KEY,
  name text,
  code text UNIQUE,
  location text,
  kabupaten text,
  status text, -- planning, active, completed
  tahap integer,
  parent_project text,
  pic text,
  start_date date,
  created_at timestamptz
)

-- Analisis pasar
market_analysis (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  kabupaten text,
  -- demografi
  population integer,
  population_growth numeric,
  kk_count integer,
  kk_growth numeric,
  density numeric,
  -- ekonomi
  umk numeric,
  avg_income numeric,
  asn_count integer,
  private_employees integer,
  umkm_count integer,
  unemployment_rate numeric,
  -- FLPP
  flpp_realization integer,
  active_developers integer,
  active_banks integer,
  -- scores (auto-calculated)
  demand_score numeric,
  market_potential_score numeric,
  market_recommendation text,
  created_at timestamptz
)

-- Kompetitor (one-to-many per market_analysis)
competitors (
  id uuid PRIMARY KEY,
  market_analysis_id uuid REFERENCES market_analysis(id),
  name text,
  price numeric,
  product_type text
)

-- Analisis lahan
land_analysis (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  land_area numeric,
  land_price_total numeric,
  land_shape text,
  contour text,
  road_width numeric,
  legal_status text,
  notes text,
  -- kalkulasi otomatis
  road_area numeric,
  fasum_area numeric,
  effective_area numeric,
  max_units integer,
  land_price_per_unit numeric,
  created_at timestamptz
)

-- Perencanaan produk
product_plans (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  house_type text,
  building_area numeric,
  land_area numeric,
  selling_price numeric,
  unit_count integer,
  target_segment text,
  competitor_price numeric,
  created_at timestamptz
)

-- Studi kelayakan
feasibility (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  -- biaya
  land_cost numeric,
  land_preparation_cost numeric,
  construction_cost_per_unit numeric,
  fasum_road_cost numeric,
  permit_cost numeric,
  marketing_cost numeric,
  overhead_cost numeric,
  contingency_percent numeric,
  -- revenue
  selling_price_per_unit numeric,
  total_units integer,
  booking_fee_per_unit numeric,
  sales_per_month integer,
  kpr_percent numeric,
  cash_hard_percent numeric,
  cash_installment_percent numeric,
  -- hasil kalkulasi
  total_revenue numeric,
  total_cost numeric,
  gross_profit numeric,
  margin numeric,
  roi numeric,
  irr numeric,
  npv numeric,
  payback_period integer,
  bep_units integer,
  risk_score numeric,
  recommendation text,
  created_at timestamptz
)

-- Milestone timeline
project_milestones (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  phase text, -- akuisisi, perencanaan, legal, marketing, konstruksi, administrasi, serah_terima
  task_name text,
  target_date date,
  actual_date date,
  status text, -- belum_mulai, berjalan, selesai, terlambat
  progress_percent integer,
  notes text,
  created_at timestamptz
)

-- Cashflow bulanan
cashflow_entries (
  id uuid PRIMARY KEY,
  project_id uuid REFERENCES projects(id),
  month_number integer,
  month_date date,
  -- cash out
  land_cost_out numeric DEFAULT 0,
  construction_cost_out numeric DEFAULT 0,
  marketing_cost_out numeric DEFAULT 0,
  operational_cost_out numeric DEFAULT 0,
  kpp_installment_out numeric DEFAULT 0,
  -- cash in
  booking_fee_in numeric DEFAULT 0,
  ht_kpr_in numeric DEFAULT 0,
  down_payment_in numeric DEFAULT 0,
  kpp_disbursement_in numeric DEFAULT 0,
  created_at timestamptz
)

-- KPP
kpp_data (
```

## UI/UX REQUIREMENTS

1. **Sidebar nested:** Saat klik menu Perencanaan di sidebar utama, tampilkan sub-menu nested (collapsible). Sub-menu yang memiliki sub-item lagi tampilkan sebagai group dengan indentasi.

2. **Breadcrumb:** Setiap halaman menampilkan breadcrumb: `Perencanaan > [Sub-menu] > [Halaman]`

3. **Project context selector:** Di bagian atas setiap halaman yang membutuhkan `project_id`, tampilkan dropdown selector proyek. Setelah proyek dipilih, semua tab/sub-halaman dalam modul tersebut menggunakan proyek yang sama.

4. **Auto-fill antar modul:** Data yang sudah diinput di modul sebelumnya harus otomatis mengisi field yang relevan di modul berikutnya (contoh: harga tanah dari Analisis Lahan otomatis mengisi HPP di Feasibility Engine).

5. **Status indicator:** Setiap sub-menu di sidebar menampilkan dot indicator: abu-abu (belum ada data), kuning (data parsial), hijau (data lengkap).

6. **Responsive:** Dashboard ini digunakan di desktop dan tablet (minimal 768px).

7. **Loading states:** Semua kalkulasi berat tampilkan loading skeleton, bukan blank screen.

8. **Empty states:** Setiap halaman yang belum ada data tampilkan ilustrasi + tombol CTA untuk mulai input.

9. **Warna status standar Satara:**
   - Hijau: on track, lolos standar, nilai bagus
   - Kuning / amber: perlu perhatian, mendekati batas
   - Merah: bermasalah, tidak lolos standar, delay signifikan

10. **Number formatting:** Semua angka rupiah menggunakan format `Rp 1.250.000.000` (titik sebagai pemisah ribuan). Persentase dengan 1 desimal. Tidak ada floating point artifacts.

## CATATAN PENTING

- Semua kalkulasi finansial harus akurat. Gunakan library `decimal.js` atau pastikan tidak ada floating point error untuk kalkulasi rupiah.
- IRR dihitung menggunakan metode Newton-Raphson atau binary search (bukan estimasi).
- NPV dihitung dengan discount rate yang bisa diubah di Settings.
- Gantt chart di Master Timeline bisa menggunakan library `react-gantt-chart` atau `@dhx/trial-react-gantt` atau implementasi custom dengan Recharts.
- Untuk export PDF di CEO Decision Report, gunakan `react-pdf` atau `html2canvas` + `jsPDF`.
- Semua tanggal menggunakan format `DD MMMM YYYY` (contoh: 15 Januari 2026).
- Semua teks UI dalam Bahasa Indonesia.
